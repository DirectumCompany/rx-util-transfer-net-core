# rx-util-transfer-net-core
Репозиторий с исходным кодом утилиты переноса настроек.

> [!WARNING]
> **Решение больше не обновляется**
>
> Начиная с версии **26.3** решение больше не обновляется на новые версии.
> 
> Как альтернативу решения, можно использовать [Утилиту импорта](https://github.com/DirectumCompany/rx-util-importdata-net-core) в связке с [экспортом списка](https://club.directum.ru/webhelp/directumrx/web/index.html?user_exportspiska.htm).
>
> Если для вас требуется обновление решения на новые версии, обратитесь в службу поддержки Directum. Опишите кейсы и объемы настроек, которые переносите.

## Описание
Утилита предназначена для переноса настроек документооборота из одной системы Directum RX в другую. Например, из тестовой в продуктивную. Подробное описание см. в [Directum RX. Утилита переноса настроек. Инструкция по использованию](https://github.com/DirectumCompany/rx-util-transfer-net-core/tree/main/Docs)

### Особенности сборки проекта
После клонирования репозитория, следует переподключить сборку Sungero.Logging.dll в проектах решения. 
Для этого, в обозревателе решений, раскройте список сборок (__Зависимости > Сборки__) и удалите сборку __Sungero.Logging__ в каждом проекте, где он используется. После удаления добавьте ссылку на сборку: __правый клик по Зависимости > Добавить ссылку на проект__.
